Form Pengajuan Klaim Ban

Isi data kendaraan, kejadian, dan pelapor, lalu unggah 9 foto kendaraan. Semua kolom bertanda * wajib diisi.

Mode uji coba: alamat server belum diisi, jadi file tidak benar-benar dikirim. Isi CONFIG.ENDPOINT di bagian script untuk mengaktifkan pengiriman.
Cara Pengisian
  1. 1Isi nomor polisi, waktu dan tempat kejadian, lampirkan Form Klaim / BAAK, serta isi data pelapor
  2. 2Unggah 9 foto kendaraan sesuai keterangan (format JPEG)
  3. 3Kirim, lalu simpan nomor tiket
